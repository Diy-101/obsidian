## Игра «Group work»
- Есть бюджет 100
- Есть выбор одновременно
- Каждый выбирает число x — деньги идущие в групповой аккаунт
- Все деньги ГА умножаются на 3
- ГА распределяются равными долями среди всех 4 игроков
- В конце деньги в бюджете + часть

**Utility** — полезность. 

| Эмоциональный канал | Рациональный канал |
| ------------------- | ------------------ |
|                     |                    |
**Социальная дилемма** — индивидуальная рациональность противоречит групповой выгоде.

**Conditional cooperation** — если я выиграл, то буду дальше помогать группе.

Проблема безбилетника — есть человека в группе, который делает минимальный performance

Public goods
- доступ всем
- не уменьшается от использования

| Public goods | Common pool resources |
| ------------ | --------------------- |
| Club goods   | Private goods         |
Club goods — нужно заплатить, чтобы войти
Common pool resources — общественные блага, но уменьшаются

**Наказание** и **shuffle** — хороший способ мотивации к кооперации
