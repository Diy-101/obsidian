## Тема «Теория игр»
Теория игр — это чисто математические игры экономических агентов.

В играх необходимо знать:
- игроки
- действия
- тайминг & информация
- исходы

Row-player — 1 игрок
Column-player — 2 игрок

Normal-form game — матрица, игроки делают одновременные ходы.
Равновесие Нэша — комбинация стратегий, при которой ни одному игроку не выгодно отклоняться.
Стратегия — план использования действий.
> Много нэшей = coordination problem.

**Chicken game** («игра в цыплёнка», или «игра в труса») — модель в теории игр, где два участника идут на конфликт: каждый хочет, чтобы другой уступил, но если не уступит никто, оба понесут большой ущерб. Классический пример: два водителя едут навстречу друг другу. Кто свернёт — считается «струсившим», но если оба продолжат движение, произойдёт столкновение.

**Bottle of sexes** — игра, в которой участники хотят действовать вместе, но предпочитают разные варианты. Например, двое выбирают, куда пойти: А предпочитает концерт, Б — футбол. При этом обоим важнее провести вечер вместе, чем попасть на любимое мероприятие по отдельности.

Решение любой игры сводится к нахождению лучшего действия для игрока 1 при действии N игрока 2.

Поиск «best response» для каждой чистой стратегии.

Дилемма заключенного.

Смешанная стратегия — иногда A, иногда B. Задача — быть непредсказуемым

Expected Utility — ожидаемый выигрыш, то есть средний выигрыш игрока при всех возможных комбинациях.
$$\large EU = \sum (вероятность\ исхода\ * выигрыш\ при\ этом\ исходе)$$

Теперь я хочу проверить, если я буду всегда выбирать только одно значение A. Беру производную и получаю увеличивает ли это вероятность моего выигрыша этот вариант.

$$ dEU/dp = 2q - 1 => q = 1/2$$
Получаем:
- Если q = 1/2, то A(1/2 * 1 + 1/2 * 0 = 1/2) и B(1/2 * 0 + 1/2 * 1 = 1/2) => мне без разницы что выбирать
- Если q > 1/2 (например 1), то A(1 * 1  + 0 * 0 = 1) и B(1 * 0 + 0 * 1 = 0) => всегда выбираю A, так как выигрываю
- Если q < 1/2 (например 0), то аналогично всегда выбираю B

|     | C    | D    |
| --- | ---- | ---- |
| A   | 1, 0 | 0, 1 |
| B   | 0, 1 | 1, 0 |
P(A) = p 
P(B) = (1 - p)

P(C) = q
P(D) = (1 - q)

$$EU = pq * 1 + p(1 - q) * 0 + (1 - p) * q * 0 + (1 - p)(1 - q) * 1$$

## Равновесие Нэша
- Чистое равновесие — «я всегда выбираю вариант A при ходе B игрока 2»
- Смешанное равновесие — «я выбираю A с вероятностью $p$, а B с вероятностью $1 - p$»
