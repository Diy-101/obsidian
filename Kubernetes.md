## Что такое Kubernetes?
**Kubernetes** — это открытое программное обеспечение, позволяющие манипулировать контейнерами и объединять в логические юниты.

Kubernetes вводит новый уровень абстракции для манипуляций над контейнерами. 
Все абстракции называются объектами. Kubernetes максимально скурпулезно сохраняет их в системе.

Логика работы всей системы Kubernetes такова:
1. Мы заключаем контейнер в POD (можно несколько контейнеров в один POD)
2. Объединяем контейнеры в Узлы (Ноды)
3. А узлы в кластеры, которые имеют супервайзера в виде мастера узлов

## Объекты/ресурсы в системе Kubernetes
### Node
### Pod
==Pod== — это строительные блоки системы kubernetes. Суть их заключается в скрывании логики работы контейнеров. В одном поде может быть несколько контейнеров, обычно не больше двух.
***Важно:***
- Если контейнеры внутри podов умирают, то pod тоже удаляется и все данные вместе с ним!
## Node
==Узлы== — это объединение подов в логические сущности удобных для упрвления в системе. Узлы делятся на ==server-node== и ==worker-node==. Server-node управляет всем кластером и другими нодами.
### Deployment
==Deployment== — это умный менеджер podов. Он автоматически следит за их жизнью. Обновляет, cоздает реплики, убивает и делает откаты при необходимости. 
## ReplicaSet
==ReplicaSet== — объект, следящий за количеством подов в deploymente.  

## Важные команды с K3d и kubectl
Во-первых, k3d — это лёгкий дистрибутив Kubernetes.
```bash
k3d kubeconfig get k3s-default — выводит базовую конфигурацию кластера.

kubectl cluster-info — аналогично команде выше, если контекст установлен. 

kubectl config use-context k3d-k3s-default — сетит контекст для kubectl.

k3d cluster start — запускает кластер

k3d cluster stop — стопает кластер

k3d cluster delete — удаляет

kubectl create deployment hashgenerator-dep --image=jakousa/dwk-app1 — создает deployment и pod и соответсвующим контейнером.

kubectl explain RESOURCE — объясняет предназначение объектов в системе.

kubectl get RESOURCE — получает те или иные объект в системе

k3d image import <image-name> — добавить в кластер image с локальной машины

kubectl edit deployment <deployment-name>  —  изменяет настройки deployment, файл по умолчанию открывается в VIM
```
